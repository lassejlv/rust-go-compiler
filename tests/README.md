# rustgo end-to-end tests

```
tests/
  run-pass/NNN_name.rs        self-contained Rust program with fn main()
  run-pass/NNN_name.stdout    expected stdout (generated by real rustc)
  run-pass/NNN_name.exitcode  expected exit code, only present when non-zero
  run.sh                      test runner for ./rustgo
  gen_expected.sh             regenerates .stdout/.exitcode with rustc
  out/                        scratch output (gitignored)
```

## Running

```sh
tests/run.sh               # go build ./cmd/rustgo, then run every test
tests/run.sh 04            # only tests whose name contains "04"
tests/run.sh -q            # print only failures + the summary line
tests/run.sh -j 8 string   # 8 parallel jobs, tests matching "string"
tests/run.sh --no-build    # skip `go build`, use the existing ./rustgo
```

For each test the runner compiles `./rustgo tests/run-pass/X.rs -o tests/out/X`
(60s timeout), runs the binary (10s timeout, cwd `tests/out`, stdin
`/dev/null`), and compares stdout byte-for-byte with `X.stdout` and the exit code
with `X.exitcode` (default 0). Stderr is not compared. A failure reports one of:
compile error/timeout (first lines of compiler output), runtime timeout, exit code
mismatch, or output mismatch (short unified diff). The last line is always
`passed X / Y`; the exit status is 0 only if everything passed. Per-test
artifacts (`X.actual`, `X.stderr`, `X.compile.log`) stay in `tests/out/`.

Environment overrides: `RUSTGO` (compiler path, default `./rustgo`), `JOBS`,
`COMPILE_TIMEOUT`, `RUN_TIMEOUT`. As a sanity check of the corpus itself,
`RUSTGO=<script that runs rustc "$1" -o "$3"> tests/run.sh --no-build` passes everything.

## Regenerating expected output

```sh
tests/gen_expected.sh [pattern]
```

Compiles each test with `rustc --edition 2021` (rustc 1.97 was used) and
rewrites the `.stdout` / `.exitcode` files. Use it after adding or editing a test.

## Test progression

Tests are numbered roughly from simplest to most advanced so the compiler can be
brought up incrementally:

| range   | area |
|---------|------|
| 001-015 | println!, integer/float arithmetic, let/mut, if, loops, ranges, functions, recursion, casts, wrapping/checked ops, bit ops, chars |
| 016-035 | tuples, arrays, slices, structs/impl, tuple & unit structs, enums, match patterns, Option/Result, `?`, if let/while let/let else, matches!, consts/statics, references |
| 036-060 | String/&str APIs, Vec APIs, 2D vecs, `{:?}`/`{:#?}`, width/fill/precision/radix formatting, float printing edge cases |
| 061-085 | traits, default methods, `dyn Trait`, generics & bounds, `impl Trait`, operator overloading, derives, Display, Default/Clone/Copy, From/Into, associated types/consts, Iterator impls, const generics, blanket impls |
| 086-105 | closures (Fn/FnMut/FnOnce, boxed, returned), iterator adaptors, peekable, sorting with closures, HashMap/HashSet/BTreeMap/BTreeSet/VecDeque |
| 106-118 | Box lists & trees, Rc/RefCell/Weak/Cell, Drop order, lifetimes, modules, macro_rules!, process::exit (`114`, exit 3), panic (`115`, exit 101), mem::swap/replace/take, slice patterns, labeled breaks, advanced generics |
| 119-130 | realistic programs: calculator, bank, matrices, sieve, word frequency, state machine, text adventure, N-queens, Dijkstra/BinaryHeap, string algorithms, sorting algorithms, JSON parser |

Rules for new tests: deterministic output only (no time, randomness, env, stdin,
file I/O, threads, addresses, or HashMap iteration order - sort keys first), and
must compile with `rustc --edition 2021`.
